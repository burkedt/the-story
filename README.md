# The Story

A phone-first slideshow of the proposal photographs. Best watched with the phone turned sideways.

## Watch

Open `index.html` through a local server (or the GitHub Pages URL). Tap **Tap to begin**. The pictures advance on their own. Swipe, or tap the left and right edges, to move between them. Tap the middle to pause. On a computer, the arrow keys and spacebar do the same.

Held upright, a phone asks you to turn sideways. **Continue anyway** plays the story in portrait. Where the browser allows it, starting the story also asks for fullscreen and a landscape lock. iPhone Safari cannot lock the orientation, so the prompt is the guide there. On an iPhone, tap Share, then Add to Home Screen, and open The Story from the icon. That launches it with no browser bars.

Portrait photographs stay fully visible on a blurred copy of themselves. Landscape photographs fill the screen.

## Publish on GitHub Pages

1. Push this folder to the `main` branch.
2. In **Settings → Pages**, set the source to `main` and the root folder.
3. Share `https://burkedt.github.io/the-story/`.

Paths are relative, so the page works under `/the-story/`. Photos stay in `images/`, in numbered order. They are already sized for the web, so the slideshow uses those files directly.
