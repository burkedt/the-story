# The Story — Proposal Gallery

A simple, phone-optimized black & white photo gallery presented as matted prints in black frames.

## How to view locally
Open `index.html` in a browser (or use a local server for best results).

## Deploy to GitHub Pages
1. Create a new repository (or use an existing one).
2. Upload the contents of this folder (or push the whole `proposal-gallery` folder).
3. Go to **Settings → Pages**.
4. Set source to the branch that contains `index.html` and the `images/` folder (usually `main` / root).
5. Share the published URL with the couple.

The gallery starts on the first photo (preloaded). Swipe left/right through the sequence. Tap **Gallery** at any time to see all ten framed prints (thumbnails load instantly; full-resolution opens on tap). Tap any photo to open a larger view with a **Save to Phone** button.
